Здесь опубликованы некоторые примеры выполненных проектов, которые демонстрируют мои навыки в области аналитики данных:

1. **Бизнес-аналитика сервиса доставки еды** (ноябрь 2025)
    - *Задача:* создание системы метрик для оценки эффективности сервиса
    - *Действия:* [рассчитаны ключевые бизнес-метрики с помощью SQL](Food_delivery_service_metrics_case.sql), создана [интерактивная BI-визуализация в Yandex Datalens](https://datalens.yandex/jxjqgitlt0jo4), подготовлен аналитический отчёт (вкладка 2 [дашборда](https://datalens.yandex/jxjqgitlt0jo4?tab=51)).
    - *Результат:* создана система мониторинга клиентской базы, подготовлены рекомендации по развитию

2. **Аналитика венчурных инвестиций** (октябрь 2025)
    - *Задача:* провести исследовательский анализ компаний, объёмов и типов привлечённых инвестиций, статистики по возвратам средств на основе исторических данных (до 2014 года); сформировать рекомендации по перспективным отраслям и типам финансирования.
    - *Действия:* подготовлены к анализу два датасета (об инвестировании стартапов и о возвратах инвестиционных вложений); исследованы динамика и структура финансирования стартапов до 2014 года; выполнен [комплексный анализ инструментами Python](Startup_investing_case.ipynb) для оценки инвестиционных стратегий и выявления закономерностей финансирования.
    - *Результат:* выявлены перспективные отрасли для инвестирования; определены наиболее уместные типы финансирования с учётом исторической статистики возвратов; подготовлены рекомендации для формирования инвестиционной стратегии заказчика.

3. **A/B‑тестирование алгоритма рекомендаций в развлекательном приложении** (декабрь 2025)
    - *Задача:* рассчитать параметры A/B‑теста для проверки гипотезы о повышении вовлечённости пользователей за счёт нового алгоритма рекомендаций; оценить корректность проведения эксперимента; проанализировать результаты теста.
    - *Действия:* рассчитаны параметры теста (размер выборки, длительность эксперимента); проверена корректность рандомизации и распределения пользователей по группам; выполнен статистический анализ результатов тестирования с применением Python.
    - *Результат:* подтверждена статистическая значимость роста ключевой метрики в тестовой группе; доказано отсутствие значимых искажений в дизайне эксперимента; сформировано обоснование для внедрения нового алгоритма рекомендаций на основе собранных данных; подготовлены выводы о целесообразности масштабирования изменения; подготовлен [отчёт о проведённой работе в Jupyter Notebook](AB_testing_case.ipynb).

4. **Продуктовая аналитика маркетплейса** (май 2026)
    - *Задача:* комплексный анализ продуктовых метрик и unit-экономика
    - *Действия:* работа с 6 таблицами в SQL, включая JSON-поля, анализ метрик в Python
    - *Результат:* выявлены ключевые драйверы роста, сформулированы продуктовые гипотезы

5. **Big Data проект для Яндекс Такси** (июль 2026)
    - *Задача:* создание автоматизированной витрины данных о поездках
    - *Действия:* разработан ETL-процесс на PySpark, настроен DAG в Apache Airflow
    - *Результат:* автоматизация обработки миллионов записей ежедневно
